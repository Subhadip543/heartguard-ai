# Final Error Analysis — HeartGuard AI

## 1. Objective

The objective of this analysis is to investigate the prediction errors produced during hospital-aware model evaluation and identify patterns that may explain differences in model performance across hospitals.

The analysis focuses on:

- False positives and false negatives across hospitals.
- Differences in error rates between hospitals.
- Missing clinical information among correctly and incorrectly classified records.
- The relationship between missingness burden and false-negative predictions in the VA hospital.

This analysis is exploratory. Its purpose is to understand model limitations, not to establish causal relationships or modify the evaluation results.

## 2. Evaluation Methodology

The analysis uses predictions generated by the hospital-aware threshold evaluation experiment.

Each hospital was treated as an outer held-out test group. Model selection and threshold selection were performed using the other three hospitals, and the selected model was evaluated on the untouched outer hospital.

The prediction file contains 918 records, with one outer-test prediction per record.

**Prediction file:**

`ml/reports/tables/threshold_predictions.csv`

Relevant fields:

| Column | Description |
|---|---|
| `record_index` | Original dataset record index |
| `held_out_site` | Hospital used as the outer test group |
| `selected_model` | Model selected for that outer evaluation |
| `selected_threshold` | Selected decision threshold |
| `actual` | Actual target |
| `predicted` | Model prediction |
| `score` | Predicted probability or decision-function score |

The analysis uses the following definitions:

- True Positive (TP): Actual positive, predicted positive.
- True Negative (TN): Actual negative, predicted negative.
- False Positive (FP): Actual negative, predicted positive.
- False Negative (FN): Actual positive, predicted negative.

Error rate is calculated as:

\[
\text{Error Rate} = \frac{FP+FN}{N}\times100
\]

## 9. Key Findings

The error analysis produced the following findings:

1. VA had the highest hospital-level error rate, at 29.65%.
2. Switzerland had a specificity estimate based on only eight negative records, making that estimate unstable.
3. VA false negatives had substantially more missing clinical features than true positives.
4. Missingness was particularly elevated for slope, oldpeak, trestbps, thalach, and exang among VA false negatives.
5. The VA false-negative rate was 4.62% among positive records with 0–2 missing features and 70.59% among positive records with 7–8 missing features.
6. The average model score for VA false negatives was 0.421, compared with 0.824 for true positives.

Together, these observations suggest an association between incomplete clinical information and the model's difficulty identifying positive cases in the VA hospital.

## 10. Limitations and Interpretation

The findings must be interpreted carefully.

### 10.1 Small Hospital Samples

The dataset contains only four hospital groups. Some subgroup comparisons, particularly Switzerland's specificity and VA's missingness groups, have limited sample sizes.

### 10.2 Observational Analysis

The relationship between missingness and false-negative predictions does not establish causation.

Missingness may be associated with other patient characteristics, hospital-specific data collection practices, or differences in the underlying patient population.

### 10.3 Exploratory Subgroup Analysis

The missingness groups were examined after observing the model's prediction errors. These results should be treated as exploratory findings rather than independently validated hypotheses.

### 10.4 No Model Changes Based on Outer-test Errors

The outer-test results were used for error analysis only.

The VA threshold and model were not adjusted using the held-out VA labels. Any future missingness-aware strategy must be evaluated using an appropriate training and validation procedure.

### 10.5 Research and Educational Scope

HeartGuard AI is an educational machine-learning prototype based on a historical heart disease dataset.

Its results do not establish clinical safety, diagnostic validity, or suitability for real-world medical decision-making.

## 11. Conclusion

The hospital-aware error analysis demonstrates that model performance varies across hospitals and that VA presents the most challenging generalization case.

A particularly important observation is the association between missing clinical information and false-negative predictions in VA.

Records with seven to eight missing clinical features had a substantially higher false-negative rate than records with zero to two missing features.

These findings highlight the importance of missing-data handling, hospital-level generalization, and careful evaluation of model errors.

The results will inform future model development, but no final model or clinical recommendation should be selected solely from these exploratory findings.
